**The Demo Punchline** is an entry for make.fun's
[$50 "The joke about the demo" bounty](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112).
Its program writes one line to `/output/entry.txt`: a one-line joke about
working beside an AI coding agent — a joke built for a room watching a demo.

## Run

```sh
python3 main.py
```

The program writes the joke to `/output/entry.txt` (UTF-8, 1–280 characters).
It needs no network.
